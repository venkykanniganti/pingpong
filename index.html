🔗 Google Sheet Integration

Option A: Publish as CSV (Easiest)

  1. In Google Sheets, go to File > Share > Publish to web.
  2. Select the worksheet with player ratings, change format to Comma-separated values (.csv).
  3. Click Publish, copy the generated URL link, and paste it into the field above.

Option B: Google Apps Script Endpoint

Attach a small doGet() script returning JSON from your Spreadsheet web app URL.
